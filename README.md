# 暗水印：技术方案与本地验证

## 目标与范围

以不影响正常操作为前提，优先研究 Windows 屏幕暗水印，覆盖普通桌面窗口、全屏及局部截图，并探索清晰、正对的屏幕照片。文件导出、受控文本复制是独立能力，不由屏幕覆盖层解决。

当前代码是**研究原型，不可用于员工终端部署或责任认定**：没有身份服务、防伪、纠错、管控、自动回滚和性能验证；不采集屏幕，不连接网络，不做自启动，不修改剪贴板及用户文件。

## 能力与方案

| 能力 | 实现思路 | 覆盖与限制 |
| --- | --- | --- |
| 屏幕覆盖 | 每块显示器一层置顶、鼠标穿透的低透明图案，图案平铺；截图端无需读取屏幕内容 | 常规窗口切换可以共用覆盖层；系统安全桌面、其他置顶窗口、独占全屏、远程桌面、投屏及各类截图工具需逐项验证，不能保证全部覆盖 |
| 局部提取 | 重复图案、同步信号、纠错和短编号 | 须实测最小有效截图尺寸、可靠提取率及误报率；任意小截图不可保证 |
| 正对拍照 | 对拍摄图像做定位、尺度和几何校正，再识别水印 | 即使正对也有采样、摩尔纹和压缩影响；当前原型尚不支持尺度搜索，也没有实拍结果 |
| 文件导出 | 在受控下载、导出或分享环节按格式嵌入；优先生成副本 | 图片、PDF、Office 分别适配；屏幕覆盖不会修改文件；不拦截或原地改写所有文件 |
| 受控文本 | 在特定应用的受控复制/分享环节探索文本水印 | 不全局改写剪贴板；排除代码、命令、URL、结构化数据等，先验证粘贴行为 |
| 溯源与管控 | 使用随机溯源码、授权查询、版本及签发审计；支持灰度、关闭和回滚 | 生产方案需认证、防伪、误报评估和隐私审查；水印仅是调查线索 |

生产端建议使用原生轻量渲染，优先静态图案和事件驱动，不持续截屏或高频重绘；以实际测试确定实现方式。需处理多屏热插拔、不同 DPI、会话切换和窗口层级，同时避免抢焦点、拦截输入或异常重启。不能假设静态覆盖层没有 GPU、内存或功耗开销。

## 本地原型

原型先生成 16 位数字的印刷体笔画，倾斜 20 度后以极低透明度重复平铺，并用固定伪随机载波承载同步信息和 CRC16。默认测试编号为 `9845456435684656`，也可以使用其他 16 位数字，保留前导零。覆盖层仅改变部分像素，默认透明度为 `0.004`，不再对整屏混色。该方案仍会改变显示像素，笔画在部分背景或显示器上可能被看到，不能保证完全不可见；发现影响体验时立即停止。

检测时，对输入图片的像素进行滤波、按固定周期做中值叠加，通过与编号无关的同步图案定位，然后逐位匹配数字字形并验证 CRC16，**不需要预设员工编号**。默认展示将周期叠加的信号重复铺回整图，便于查看，但不代表图上每处都是独立提取的水印；复杂背景也可能产生伪影。校验通过时，界面会另行以印刷体重建并显示解码结果。CRC 只能检错，不能防伪或证明身份。

默认强度下，合成的未压缩图片及局部裁剪能匹配预设编号；一次 JPEG 质量 90 的合成测试未匹配成功。真实桌面截图、缩放及手机拍照仍未验证，特别是低强度下的压缩和拍照识别不能保证。新版与此前水印原型不兼容。

### 安装

在 Windows PowerShell 执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 运行与停止

在交互式桌面运行，示例编号不对应真实员工：

```powershell
.\.venv\Scripts\python.exe overlay.py
```

如需测试另一个编号，使用 `.\.venv\Scripts\python.exe overlay.py --id 1234567890123456`。

控制窗口点击“停止水印”或关闭窗口退出。实验时如需中止，也可在启动它的终端按 Ctrl+C。实验版不自动重建显示器变化后的覆盖层；连接、断开显示器或调整分辨率后需重启。使用时请确认覆盖层没有影响鼠标和键盘；一旦出现影响立即停止。

启动检测工具，复制截图后点击“粘贴图片”或按 Ctrl+V，工具会自动分析：

```powershell
.\.venv\Scripts\python.exe detector.py
```

工具在本地显示原图、整张图片的周期叠加重建结果和解码结果。重建图按窗口尺寸缩放显示，计算结果仍与输入图片同尺寸；背景纹理和噪声也可能被增强。即使解码失败也会显示重建图供人工观察；重建图不代表每处都是图片中的独立水印，需要结合原图和背景判断。印刷体重建文字仅在 CRC 校验通过后显示，不应与周期叠加图混淆。

注意区分复制图片文件与截图：从聊天软件截图或截取图片窗口时，当前电脑的屏幕覆盖层也可能被截入；复制聊天软件提供的图片内容通常不会额外捕获桌面覆盖层，但具体以软件行为为准。建议先停止覆盖层，再复制或打开保存的原照片对比。“增强原图像素”可切换到不做周期重建的对照视图。

点击“放大增强图”或双击右侧增强图，可打开全图查看器；用鼠标滚轮或加减按钮缩放，按住左键拖动，也可通过滚动条移动。查看器从完整增强图取可见区域，不只是放大主窗口中的缩略图。

如果拍照后水印笔画比较淡，可选择“照片像素增强”的亮度、红色、绿色或蓝色通道，以及不同强度，再点“增强原图像素”。该模式对照片全图做局部对比度增强，不需要知道水印周期或编号，不执行编号解码；也会放大文字边缘、摩尔纹和噪声，不能作为水印或身份的证明。可在增强后放大查看；如果细节在拍摄或压缩过程中已经丢失，单纯增强无法恢复。

如果输入是完整屏幕的照片，可点击“校正屏幕照片”，按左上、右上、右下、左下的顺序点击屏幕画面的四个角，填写被拍屏幕的**实际像素分辨率**，再点击“校正并检测”。工具使用透视和尺寸校正后的图像解码，并将周期叠加结果映射回整张照片。此方式不适用于缺少屏幕边缘的局部照片；照片失焦、压缩或水印信号丢失时不能保证恢复。

也可将截图保存后通过命令行提取：

```powershell
.\.venv\Scripts\python.exe extract.py "截图.png"
```

`detected: true` 表示同步分数达到实验性阈值且 CRC 校验通过，不证明身份或真实性；`false` 也不能证明图片没有水印。不要使用含敏感内容的截图作为测试样本。

### 自动验证

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

自动测试仅使用程序生成的合成图，覆盖完整图、错位裁剪、明暗背景、无水印样本，以及模拟透视变换与全照片输出。它不验证真实桌面、所有窗口、肉眼不可察觉、性能或真实手机拍照。

## 实现进度

**已实现：实验原型**

- Windows 多屏覆盖层、鼠标穿透、手动退出；20 度倾斜的 16 位数字水印和 CRC16。
- 本地检测工具支持粘贴或打开图片、全图像素增强及缩放拖动查看、独立解码不同编号；支持对完整屏幕照片手动选择四角并校正透视和分辨率。
- 12 项自动测试覆盖合成截图、多个编号、局部裁剪、模拟透视以及照片非屏幕区域保留。

**未实现或未验证**

- 自动识别屏幕四角、局部屏幕拍照矫正、失焦/摩尔纹/压缩增强和稳定的照片识别；用户反馈拍照可看到水印，但内容不清晰，尚无真实照片样本及量化结果。
- 文件导出水印、文本水印、账号设备映射、真实身份溯源和防伪。
- macOS、特殊全屏与安全桌面适配、多屏热插拔自动重建、灰度下发、健康监测与自动回滚。
- 肉眼无感、用户操作不受影响、CPU/GPU/内存/功耗影响及不同应用和采集路径的系统性验收；当前方案未达到生产上线条件。

## 验证与上线门槛

1. 使用无敏感信息的样本，分别测试浅色、深色、密集文本、图片和视频背景；记录水印视觉可见程度。
2. 测试各截图工具、多屏、DPI、应用切换、置顶窗口、远程桌面和屏幕共享，记录采集路径及覆盖例外。
3. 按截图尺寸、裁剪位置、压缩质量分组记录提取成功率；使用无水印样本测试误报，并记录样本量。
4. 使用真实屏幕和手机清晰正对拍照，记录型号、亮度、距离、照片分辨率以及提取率；目前尚无相关结论。
5. 对比启用前后的 CPU、内存、GPU、功耗、应用响应和视频帧率，按实际设备基线确定阈值并长时间测试。
6. 验证关闭、崩溃恢复、灰度与回滚，完成隐私和安全审查后，再决定是否进入试点。
